# 我们对 qq-bridge 做了什么

## 它不是我们写的

`qq-bridge/` **fork 自 [Derpyu520/qq-bridge](https://github.com/Derpyu520/qq-bridge)**（MIT）。

原作者写的是一个「QQ ↔ DeepSeek Harness」的桥接，功能完整、有发布版本、有测试脚本。
**我们是在它上面改的，不是从零写的。**

原始 LICENSE 原样保留在 `qq-bridge/LICENSE`。

---

## 我们改了什么

改动集中在**一个文件**：`qq-bridge/src/bridge.js`（约 13,000 行，几乎所有改动都在这里）。
另有少量改动在 `src/mcp-snowluma-safe.js`、`plugins/`。

### 1. 唤醒调度：从"每条消息都回"变成"它自己有作息"

**原版**：收到消息 → 叫醒 agent → 回复。

**我们加的**：
- **`selfTime`**：每 20 分钟自己醒一次，没人说话也醒
- **她自己定的钟**：agent 可以调 `qq_set_wake_config` 决定下次什么时候醒、什么条件醒
- **长睡**：可以睡到某个时间点，期间不消耗

**为什么改**：原版是"消息驱动"，我们想要的是"它自己有一段时间"。
一个只在你说话时存在的东西，不会长出任何自己的东西。

### 2. 会话轮换：到阈值换页，而不是截断

**原版**：上下文满了就截断旧消息。

**我们加的**：上下文到 60k token 就**开一个新会话**，并让旧会话的摘要带过去（"换页交接"）。

**为什么改**：截断会让它突然忘记刚才聊什么；换页至少给了一次"交接"的机会。

### 3. 发送控制：分条、节奏、配额

**加的**：
- 一次回复拆成多条（模拟人打字）
- 条与条之间有随机间隔
- 每分钟/每小时发送上限
- 白名单会话不受限

**为什么改**：一段 500 字的话砸过来不像人；一条一条说才像。

### 4. 记忆接线（最大的改动）

**原版**没有长期记忆，只有一个会话内的上下文。

**我们加的**：
- 每条消息写进 `rix-brain` 的短期记忆
- 唤醒时调 `memory_recall` 把相关日记注入
- 沙箱操作单独记成 `kind:'tool'`（见下）

### 5. 沙箱工具（`/api/sandbox/run`）

**加的**：让 agent 能在一台 WSL 里执行命令，输出回灌到会话。

**踩过的坑**（`bridge.js` 里有注释）：沙箱输出一开始被记成 `{self:false, sender:'沙箱'}`，
等于"一个叫沙箱的人给她发消息"。三天后发现短期记忆里 1336/1500 行是机器日志，
**真人的话全被挤出去了**，而且身份标签把机器当成了对方的名字。

**修法**：给它一个独立类别（`kind:'tool'` → 记录成 role「工具」），
而不是删日志——**她仍然需要看到自己在机器上干了什么**。

### 6. 安全：从"拦"改成"脱敏"

**原版**：发送前用正则拦敏感内容，命中就**整条丢弃**。

**我们改成**：命中就**脱敏后发送**（把路径、token 换成 `***`），句子保留。

**为什么改**：实测有四条消息被整条吞掉，全是她自己贴了自己的笔记路径。
**她的句子不该因为一个路径符死掉。**

### 7. 工具裁剪

`plugins/qq-agent-presets/qq-tool-restrict.mjs`：把 55 个工具裁到 42 个，
砍掉从没被调用过的（文件发送、记忆合并、配额查询等）。

**为什么**：工具 schema 每轮都占 token，55 个大约 19k token——**那是每一轮都在付的钱**。

## 我们没改的

- `dsh-client.js`（DSH 的 HTTP 客户端）——原样，除了加了一个超时参数
- 控制台 UI（`public/console.html`）——原样
- 大部分 `scripts/`——原样

---

## 如果你想用这个 fork

**先看原项目。** 它更干净、更通用、文档更全。

**我们这个 fork 是为一件事改的**：让一个 agent 在 QQ 上"像有作息地活着"。
如果你要的正是这个，直接拿走；如果你要的是通用的 QQ 机器人桥接，**用原版**。
