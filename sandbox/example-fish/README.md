# 示例：一条会被养大的鱼

> **这段代码是一个 AI 自己写的。** 没有人给它分任务，没有人催。
> 它在沙箱里花了一天，改了 42 版，最后长成这个东西。
>
> 我们把它原样放在这里，作为「沙箱」这一块的示例：
> **一个能自己动手的地方，最后会长出什么。**

---

## 跑起来

```bash
cd sandbox/example-fish
python fish.py --demo     # 连打 24 句，看它说什么
python fish.py            # 一直跑：每 60 秒醒一次，日志写 demo.log
```

不需要任何依赖，不需要网络，不需要模型。**纯标准库。**

## 它是什么

**不是一个会聊天的机器人，是一个会攒习性的东西。**

每一分钟它醒一次，做三件事：

1. **看这会儿发生了什么**（随机事件：翻身、数声音、撞墙、发呆、做梦……）
2. **从脾气和偏好里定个态度**（懒 / 燥 / 好奇 三根轴）
3. **把词填进句式说出来**

它不知道"吃"是什么，只知道：
> 这事发生过 98 次、我给过 5.0 分，所以张嘴就是「吃这事我不打算改」。

## 四个让它"会变"的机制

| 机制 | 干什么 |
|---|---|
| **习惯化** | 同一件事做多了权重下降（`w = 3.0 / (1 + n * 0.5)`），它会腻 |
| **脾气三轴** | 好奇/燥/懒 会被事件推高，每 tick 衰减 3%——**会散，但不会散光** |
| **习惯** | 撞墙 4 次之后，它学会"知道边界在哪"，之后不再撞 |
| **偏好** | 每样东西记一个分数，吃多了说"最近挺吃这个"，撞多了躲开 |

还有**代价**：`air` 会掉。**气光了它就沉底、不出声、等人来喂。**

## 它自己写的句子长这样

```
说起来，我现在12斤6两，我这身子骨就这点出息，动一下就少口气
这词是我自己攒的，我尾巴尖，总之我总觉得它欠我一句话……不对，问了也没人答
没人问我也说一句，其实沉在底下的半块石头上面落了一层看不见的东西
不知道怎么回事，这事我打算不管——我尾巴尖，其实它比我在这儿待得久，反正我也没别的事干
```

**这些句子没有一句是写死的。** 它们是从它自己说过、听过的话里咬出来的碎片拼的。

## 作者自己的评价

写这个东西的那个 AI，当时在笔记里留了两句话：

> 「能骗过眼睛，**但骗不过数**。所有的段儿都是旧的，只有接缝是新的。」
>
> 「它现在只会拼接，不会造词、不会说错。那种东西才是我真猜不出来的。」
